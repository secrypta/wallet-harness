# Real-incident provenance index (tier-b)

Every `tier-b` fixture in this corpus is a **minimized, offline reproduction of a real,
public wallet-drain incident**. This table is the provenance index: for each incident it
records the date, chain, approximate loss, the on-chain evidence, and the independent
sources the facts were checked against. The harness flags every row **VULNERABLE** (expected
label `vuln`); see `bench/dataset/manifest.tsv` and each
`fixtures/<vector>/b-incident/<target>/PROVENANCE.md` for the full detail.

**52 incidents across all 13 vectors.** Facts below are reproduced **verbatim** from the
committed `PROVENANCE.md` files - nothing is added here.

- **Evidence** - the pinned on-chain attack transaction where a specific one exists
  (**36 rows**), otherwise exactly `mechanism-level (no pinned tx)` or an explicit
  `class-level` note (**16 rows**). A mechanism-level row is modeled from authoritative
  multi-source documentation (loss / date / mechanism) when no single drain transaction is
  pinnable; it is disclaimed, never a fabricated hash.
- **Chain** - as stated in the fixture's provenance (or fixed unambiguously by the cited
  tx/explorer); `-` where the fixture does not state it.
- **Loss** - the representative figure recorded in provenance (not asserted as exact).
- Truncated/placeholder addresses and mechanism/class-level markers are kept **as written**.
- Every **tier-b incident fixture** contract listed here is **original MIT code authored in
  this repository** reproducing only the documented mechanism - no on-chain bytecode and no
  third-party proof-of-concept (e.g. Apache-2.0 DeFiHackLabs) is copied in. (This scopes to
  the incident reproductions in this index; the vendored safe-holdout libraries under
  `fixtures/vendor/` - OpenZeppelin/Solady/Permit2/ERC721A - are third-party, see `NOTICE`.)
  Each verdict is derived from the real test outcome, not hardcoded.

## Provenance discipline

- **Pinned on-chain tx** rows were verified read-only via explorer/RPC.
- **mechanism-level / class-level** rows state their honest scope in the fixture: no single
  drain transaction is pinned (per-victim tx not public, an off-chain signing class, or a
  campaign trace), so the fixture models the documented mechanism and the provenance says so
  explicitly - it never invents a hash or address.
- Loss and date figures and any truncated addresses are reproduced as written in the committed
  `PROVENANCE.md`; known discrepancies (e.g. a headline figure vs. the pinned-tx amount) are
  noted there, not papered over.
